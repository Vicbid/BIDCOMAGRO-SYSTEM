WOS · Pedidos y Despachos
Recuperar Thread IDs perdidos
Busca en Gmail el hilo original de cada pedido que tenga col R vacía y restaura el Thread ID. Permite que los emails de despacho/faltante se envíen como respuesta en el hilo correcto.
Recuperar pedidos no registrados
Reconstruye en "Pedidos_resellers" pedidos que se crearon bien (el reseller recibió mail y PDF) pero por algún problema no quedaron registrados ahí — usa el respaldo de PEDIDOS_REPUESTOS. Nunca duplica un pedido que ya esté presente.
Instalar detector automático de respuestas
Crea el trigger que escanea Gmail cada 10 minutos para detectar respuestas A/B de resellers. Debe ejecutarse una vez desde el editor del proyecto WOS.
Apps Script → WOS → WOS_instalarTriggerDetector()
Instalar trigger de backorder
Crea el trigger diario que detecta automáticamente pedidos con demanda perdida (CANT_CANCEL > 0) y genera las notas de compra pendientes. Ejecutar una vez desde el editor del proyecto WOS.
Apps Script → WOS → WOS_instalarTriggerBackorder()
HUB PRO · Órdenes de Trabajo
Instalar triggers SLA y reporte mensual
Instala el trigger diario de verificación de SLAs (8 AM) y el trigger de reporte mensual. Ejecutar desde el editor del proyecto HUB PRO.
Apps Script → HUB_PRO → instalarTodosTriggers()
Diagnóstico del sistema HUB
Verifica resellers con email configurado, cuota de mail y acceso a hojas. El resultado aparece en los logs del editor.
